**Сведения о фронтенде**

Для отображения в браузере напишу страницу и js-код.

Для отображения поверхности в 3D будет использоваться three.js (очень крутая библиотека), для отображения рейкастинга обычный холст (встроенные методы в js).

Будет файл index.html, в нём будет небольшая разметка, на левой стороне экрана будет холст для three.js (и подключен скрипт из папки), на правой — холст для рейкастинга (скрипт тоже подключён, будет отрисовка для холста). <br>
Также будут файлы с описанием самой математики и процесса расчёта геодезических и выбора пикселей для отрисовки на холсте. <br>

В фронтенде вообще не разбираюсь, судя по всему, запуск будет через npm.

Установка npm:

```bash
curl -o- https://githubusercontent.com | bash && export NVM_DIR="$HOME/.nvm" && [ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh" && nvm install --lts && nvm use --lts
```

Проверка:
```bash
node -v
npm -v
```

Затем в папке с проектом необходимо создать или запустить или хз, как это называется модуль (?):
```bash
npm init -y
```

Должен создаться файл `package.json`

И потом уже можно устанавливать модули:
```bash
npm install three
```

При этом, будет создана папка `node_modules`, и туда будут сохраняться все эти библиотеки/модули.

При этом, в `index.html` скрипты должны подключаться с атрибутом модуля:
```html
<script type="module" src="main.js"></script>
```

Затем нужно будет запустить сервер:

```bash
npx serve .
# или, если первая не работает:
npx http-server .
```

Терминал выдаст ссылку вида `http://localhost:3000` (или 8080), по ней нужно перейти.

#### Как отрисовывать пиксель?

В стандартном HTML5 Canvas (2D контексте) нет одного прямого метода `drawPixel(x, y, color)`, но решить эту задачу можно тремя разными путями в зависимости от ваших целей.
Ниже приведены способы отрисовки прямоугольника и пикселя от самого простого до самого быстрого.

1. Как отрисовать прямоугольник (Базовый метод)

Для прямоугольников в Canvas есть готовые встроенные методы. Перед отрисовкой нужно обязательно задать цвет через fillStyle.
```javascript
// 1. Задаем цвет заливки (поддерживает hex, rgb, названия цветов)
ctx.fillStyle = '#00ff00'; // Зеленый

// 2. Рисуем заполненный прямоугольник: ctx.fillRect(x, y, width, height)
ctx.fillRect(50, 50, 150, 100); 

// 3. Если нужен только контур прямоугольника:
ctx.strokeStyle = 'red';
ctx.lineWidth = 2;
ctx.strokeRect(250, 50, 150, 100);
```

2. Как отрисовать один пиксель (Способ А: Простой)

Самый очевидный способ нарисовать пиксель — это отобразить прямоугольник размером 1x1. Для простых проектов и тестов этого более чем достаточно.
```javascript
function drawPixel(x, y, color) {
    ctx.fillStyle = color;
    ctx.fillRect(x, y, 1, 1); // Рисуем квадрат размером 1 на 1 пиксель
}

// Использование:
drawPixel(10, 20, 'blue');
```

3. Как отрисовать пиксель (Способ Б: Профессиональный для Raycasting)

Если вы пишете Raycasting-движок (подобный Wolfenstein 3D), отрисовка тысяч отдельных пикселей через fillRect(x, y, 1, 1) в цикле начнет сильно тормозить (поскольку браузер будет пересчитывать векторную графику для каждой точки).
В таких задачах работают напрямую с массивом пикселей экрана (ImageData). Вы заполняете массив в памяти (как буфер кадра), а затем за один проход выводите его на экран.
```javascript
// 1. Создаем буфер пикселей на весь размер canvas (например, 800x600)
const width = canvas.width;
const height = canvas.height;
const imageData = ctx.createImageData(width, height);
const data = imageData.data; // Одномерный массив RGBA значений

// 2. Функция быстрой записи пикселя в буфер
function setPixel(x, y, r, g, b, a = 255) {
    // В массиве data на каждый пиксель идет 4 элемента: R, G, B, A
    const index = (y * width + x) * 4;
    data[index]     = r;   // Красный
    data[index + 1] = g;   // Зеленый
    data[index + 2] = b;   // Синий
    data[index + 3] = a;   // Прозрачность (Альфа-канал)
}

// 3. Заполняем пиксели в цикле (работает мгновенно)
for (let x = 0; x < 100; x++) {
    setPixel(x, 50, 255, 0, 0); // Рисуем красную горизонтальную линию по пикселям
}

// 4. Отрисовываем весь буфер на холст (вызывать в конце кадра анимации)
ctx.putImageData(imageData, 0, 0);
```

#### Как передавать цвет?

Передать цвет в формате RGB можно стандартной строкой JavaScript. Браузер принимает ее точно так же, как и в обычном CSS.
Вот основные способы записи в зависимости от того, какой метод отрисовки вы используете.

Вариант 1. Для методов fillRect, stroke и градиентов (Строковый формат)

Вы передаете цвет в свойство fillStyle или strokeStyle в виде строки "rgb(r, g, b)" или "rgba(r, g, b, a)" для прозрачности.
```javascript
// Обычный RGB (значения от 0 до 255)
ctx.fillStyle = 'rgb(255, 99, 71)'; // Томатный цвет
ctx.fillRect(50, 50, 100, 100);

// RGBA с прозрачностью (четвертый параметр от 0.0 до 1.0)
ctx.fillStyle = 'rgba(0, 0, 255, 0.5)'; // Полупрозрачный синий
ctx.fillRect(100, 100, 100, 100);
```

Динамическое изменение цвета (через переменные)

Если компоненты цвета меняются в коде (например, зависят от расстояния до стены в Raycasting), используйте шаблонные строки (обратные кавычки `):
```javascript
let r = 255;
let g = 128;
let b = 0;

ctx.fillStyle = `rgb(${r}, ${g}, ${b})`;
```

Вариант 2. Для работы с пиксельным буфером (ImageData)

Если вы используете продвинутый метод с массивом пикселей (который мы разбирали в прошлом шаге), вам не нужно формировать строки. Вы передаете чистые числа прямо в элементы массива:
```javascript
// Наш буфер принимает компоненты цвета как отдельные числа
function setPixel(x, y, r, g, b, a = 255) {
    const index = (y * canvas.width + x) * 4;
    data[index]     = r; // Число 0-255
    data[index + 1] = g; // Число 0-255
    data[index + 2] = b; // Число 0-255
    data[index + 3] = a; // Число 0-255 (альфа)
}

// Использование:
setPixel(10, 10, 255, 99, 71); 
```

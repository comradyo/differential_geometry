# Демонстрационная программа

Пора начать реализовывать демонстрационную программу

Вопросы:
- Что такое камера, что за сущность будет задавать её положение, направление взгляда, поле зрения?
- Как будет происходить движение? Что за сущность будет задавать шаг? Как будет происходить смещение? 
На сколько нужно будет двигаться вдоль геодезической? Будет ли это одинаковое расстояние в объемлющем пространстве?
- Какой вектор будет задавать направление взгляда? Как этот вектор будет меняться при движении? Как этот вектор будет меняться при повороте?

По идее, это будет вектор в касательной плоскости (которая является евклидовой), и при повороте должен меняться только угол его поворота, но не длина.

- Как будет происходить движение, если нажимать боковые клавиши?

По идее, это будет движение по геодезической, направленной вдоль вектора, перпендикулярного вектору взгляда, и направленного вправо (или влево).

Нужно ли вообще двигаться вбок по геодезической? По идее, да, ведь это будет аналогия движения вбок в евклидовом пространстве, а это движение по прямой.

Только если сдвинемся на один шаг влево, то как тогда поменяется вектор взгляда? По идее, он должен быть всегда перпендикулярен вектору движения

- Экспоненциально отображение, где оно тут нужно?

А, кстати, возможно если буду использовать экспоненциальное отображение, то прообразом будет некоторый сегмент касательной плоскости (трапеция), а образом - геодезические для каждой из точек этой трапеции?

- Как будет строиться ортонормированный базис? Относительно чего? Как будет сохраняться ортонормированность при движении? Будут ли сохраняться координаты векторов в касательной плоскости при движении?
